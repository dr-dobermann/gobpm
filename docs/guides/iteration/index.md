# Iteration

When a single activity needs to run more than once, gobpm offers standard loops
for condition-driven repetition and multi-instance markers for fanning out over
a collection, sequentially or in parallel. Each guide includes a runnable example.

- [Standard Loop](standard-loop.md) — sequential, condition-driven repetition. *(`standard-loop`)*
- [Multi-Instance](multi-instance.md) — collection fan-out, sequential or parallel. *(`multi-instance-sequential`, `multi-instance-parallel`, `multi-instance-behavior`)*
